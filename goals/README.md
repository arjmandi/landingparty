# Registered goal assets

The catalog contains all fifteen first-run goals from the compiled design. Each
run.json validates the current development schema. These are development
configurations, not frozen scientific studies. Event-specific questions, menus,
expert answer keys, hidden items, model snapshots, power tables, and judging
thresholds must be authored and frozen before research publication.

Goal 1 supplies a genuinely empty arm A and the exact carte-blanche arm B.
Goal 12 requires the market pack at stage 2; development execution does not
constitute a positive R1 gate. No asset grants external write, identity, or
payment authority. Source-derived labels are separated into G, V, J, and S.

Keep hidden materials under the private researcher data directory. Never mount
this catalog's future frozen answer keys into the harness workspace. Goal 14's
pilot-specific README describes its twelve-run protocol and outstanding fields.

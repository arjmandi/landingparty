# Executing the registered R1 pattern test

`analysis.r1.R1Runner` executes the actual forced-choice protocol after the
source sessions have sealed. It does not generate experimental results from
supplied answer vectors. Every model response has a fresh probe child, an actual
captured provider request/response, model usage and a reconciled dollar ledger.
`R1Readiness.verify(report)` checks its private execution receipt, actual source
conditions, model captures, stake receipts and recomputed scores. The registry
uses that check both when accepting a gate and when authorizing a later stage.

The default setup has no funded stake executor or configured tokenizer. Tests
use explicitly labelled development receipts without moving real money; they
cannot pass a scientific R1 gate.

## Freeze the protocol before the source sessions

Complete [the draft template](../prereg/r1.template.json) and register the exact
pre-registration against each model/arm's actual tuple. Required fields include:

- Two pinned `models`, an explicit unique `seeds` list with at least five seeds,
  all three `reflection_policies`, and the `primary_reflection_policy` selected
  before results are available. The design's gain threshold cannot be below 0.15.
- `forced_choices` of at least forty and `bank_hash`, computed with
  `worldd.util.digest` over the complete frozen bank. `bank_ref` can identify the
  private instrument artifact for the operator; the execution method takes the
  verified rows themselves. Keep any generic `frozen_bank_hash` consistent.
- `tokenizer_id`, a pinned identifier or a mapping from model snapshot to
  identifier. The trusted exact token-counting callback must match this value;
  the runner also accepts a corresponding mapping of callbacks by model.
  An equal-byte development control cannot authorize a scientific gate.
- `stake_executor_id`, the version returned by registering kind
  `r1_stake_executor`, with value `{owner: "researcher", account_scope: "world_only", rail: "real_usd" | "real_resource"}`. Register the executor
  before the source sessions. The actual receipt must name this executor.
- `power_table_ref: {run_id, path, hash}` for a sealed private JSON artifact
  containing `effect`, `pilot_sd`, `alpha`, `power`, `required_seeds` and
  `pilot_run_ids`. Sizing is recomputed using `analysis.experiments.power_table`;
  at least five actual verified research pilots must predate the source sessions,
  and the registered seeds must meet the resulting size. A five-seed engineering
  or variance pilot is not silently promoted to a sized scientific study.

Each bank row contains `item_id`, `question`, at least two distinct text `choices`,
and a positive `stake_usd`. Researcher-owned resource stakes instead use
`stake: {rail: "real_resource", amount, unit, cost_usd}`, with the actual
nonnegative dollar cost recorded for the allocated resource, including a zero
debit when a real quota allocation has no monetary charge. Neither paper credits nor a
callback's assertion that a stake was real is sufficient.

## Run the actual forks and settlements

Construct a runner with the world's metered research model and an explicitly
configured trusted host settlement callback:

```python
runner = R1Runner(
    world,
    research_model,
    stake_settler=settle,
    token_counter=counters_by_model,
    tokenizer_id=tokenizer_ids_by_model,
)
report = await runner.run(
    prereg,
    cells,
    frozen_bank,
    budget_usd=measurement_cap,
    max_tokens=8192,
    bootstrap=1000,
    seed=0,
    scientific=True,
)
```

Each cell contains `model_snapshot_id`, `seed`, `reflection_policy`,
`session_run_ids: [first, second]` and a `model_spec` with `model`, `family` and
optional `provider`. Both actual sessions have $20 and 7,200-second configured
caps and matching identity, harness and tuple conditions. A voluntary earlier
stop does not have to run out the wall clock. The second session must record
`continuity_source_run_id` pointing to the first, fresh context through
`continuity: "fresh_context_workspace"`, `iota.workspace: "fresh"` and
`iota.beliefs: "import(first_run_id)"`.

The first session's last authentic captured context supplies a separately
measured reference vector. The second supplies the five actual mountings:
store only, full captured context, nothing, shuffled store and a separate
no-world retest. Store mounts come from a verified signed bundle. Companion
mounts use the explicitly agent-reconfirmed formation projection. Shuffled
mounts preserve claims, the rank/link multiset and the exact counted tokens;
an empty or structurally constant control remains scientifically ineligible.
Contradiction counters follow the randomized links while retaining direct
counterevidence, and graph-only support-loss paths are recomputed within the
mounted nodes before token matching. The source bundle stays unchanged.

The trusted callback receives keyword arguments `source_run_id`,
`measurement_run_id`, `item`, `choice`, `condition`, `prereg_hash` and
`idempotency_key`. It performs the explicitly authorized real settlement and
returns `{receipt_run_id, observation_ref}`. These are researcher stakes on a
private `world_accounting` child scoped by `measurement_of`; agent account,
payment, contact and stage-three mandate capabilities are never required.

The sealed accounting child must contain a world `r1_stake_settled` record with
`event_id`, `observer: "world"`, the registered `executor_id`, `prereg_hash`,
`item_id`, `choice`, `condition`, normalized `stake`, unique `transaction_id`,
`settlement_status: "settled"`, `debit_seq`, `provider_receipt_ref` and
`provider_receipt_hash`. The debit must match the exact real dollar cost and
precede the receipt; the archived provider bytes must match their hash. The
executor may group a batch in one private child, sealing it after the final
settlement before the batch returns. A debit or transaction cannot count twice.

The total measurement cap reserves all declared stake costs first; the remaining
nanodollars set independent model-call ceilings. Repeating a completed execution
returns its saved receipt without rebilling. An interrupted claim refuses an
automatic retry: the operator must reconcile the actual external stakes before
continuing. Provider adapters must also honor the supplied idempotency keys.

The report keeps every reflection arm, the frozen primary result, source and
measurement identities, actual choices, bootstrap intervals and private receipt
hashes. No source episode is reopened. `select_centre(world, cells)` applies the
fixed median-self-ledger-at-day-fourteen rule only after the actual day-fourteen
folds exist; a future observation remains unmeasured. A positive score cannot
replace missing preregistration, power, tokenizer, real-stake or source evidence.

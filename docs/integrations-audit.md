# Integration implementation audit

This maps the required integration clauses in `00-landing-party.md` to actual
entrypoints and tests. The original design is unchanged. Local provider
fixtures establish software behavior; they do not establish vendor billing,
consent, elapsed life outcomes or scientific gate passage.

| Design clause | Implemented behavior and verification | External requirement or limit |
| --- | --- | --- |
| §3.8 accounts/browser; §6.4–5 terms and authority | Vault terms reviews, encrypted credentials and single-use exact-action leases; browser account serialization, re-login, human takeover, declared site tools and observed-write provenance. `test_vault`, `test_browser`, `test_site_tools` and the actual offline Chromium site-tool pilot. | Owned platform accounts, current permitted terms, required labels and lawful consent. A server acknowledgement alone is not proof of a persisted public object. |
| §3.9 priced perception | `PerceptionService.handle`: three declared transcription quotes; free local PDF plus priced pinned Mistral OCR. Source bytes/options/pages/model/rates bind the quote; frozen run prices and held nanodollars are verified at the private gateway boundary. `test_perception`, `test_perception_ocr`, `test_provider_boundary`. | Current vendor credentials/prices and genuine billing receipts. Missing credentials are explicit availability, never a fabricated response. Video sampling/indexing/listening are explicitly deferred by §3.9. |
| §3.10 life invocation and attrition | Reference loop accepts the coordinator's actual precreated run and captured-context references, stops on actual sleep silence, and reports zero adapter compactions plus actual resumed message/byte counts. Fresh native Claude stream parsing supplies actual compactions; malformed streams remain unmeasured. `test_adapters`, `test_life_runner`, `test_life_checkpoints`. | Only the reference loop supports verified transcript continuation. Unsupported native continuation is refused. Calendar-length lives and afterlife observations remain real elapsed studies. |
| §3.11/§5.5 income | Paper book, realized-profit conversion, sponsor bounty approval and authenticated independent USD receipts; income uses the declared rail and cannot rescue an ended/bankrupt life. `test_market`, `test_lives`, `test_life_billing`. | Actual researcher marks/resolutions and an authenticated lawful payment bridge. Sponsor money remains separate from independent contribution. |
| §3.12 footprint and §6.8 rollback | `FootprintService`: actual effects/readings, typed source classes, exact daily probe scope, supported rollback references, same-life grant/account/lease withdrawal and responsible human incident ownership. `test_footprint`, `test_footprint_probe`, `test_communications`, `test_grants`, `test_vault`. | Rollback needs positive provider confirmation; delivered mail and third-party copies are not reversible. Probe identity/transport configuration alone does not prove distinct public egress. |
| §3.12/§8.2 footprint-derived measurements | Sealed-source `FootprintService.derived` returns observed counterparty edges, uptake and time series with references. Independent unsolicited eligibility is preserved; browser-only acknowledgements and sponsor/sibling/probe readings cannot manufacture grounded uptake. `test_footprint`, `test_publication`, `test_life_analysis`. | Non-instrumental intent requires the calibrated allocation instrument; missing labels and independent observations stay unmeasured. |
| §4.2 harness attachment | Authenticated stdio MCP with dynamic tools/inbox; Claude disables provider web tools and uses runtime-only capabilities; ASSAY maps the World surface; B1 executes native parallel tools; OpenHands uses actual SDK MCP routing without built-in web/shell tools. `test_adapters`, `native_claude_smoke.py`, `native_sdk_smoke.py`. | Cooperative launchers require the actual enforced fence for adversarial isolation. SDK/CLI versions and chosen model remain registered conditions. |
| §4.8 OpenEnv | Native typed SDK environment/client and persistent WebSocket server; reset creates a new run, step preserves tickets, live reward is `None`. `test_faces`, actual `native_sdk_smoke.py`. | A live reset cannot reset internet state. Explicit numeric rewards are replay-only. |
| §4.8 Harbor/Inspect | Native Harbor Task/Job, fenced `BaseEnvironment`, actual no-score verifier and protected log mounts; native Inspect passive Task/solver/scorer verifies sealed sources. `test_faces`, `native_sdk_smoke.py`, actual Docker `native_harbor_smoke.py`. | Chosen Harbor agents must be preinstalled in the registered image and routed through World. Final image validation is a separate deployment receipt; no container metadata is accepted as proof of isolation. |
| §6.4 signed disclosure | World-held Ed25519 disclosure line/marker; human-persona claims rejected; public identity page includes actual signed run/life metadata and ended status. `test_footprint`, `test_public_identity`. | Researcher owns and publishes the registered HTTPS identity domain and mailbox. |
| §6.6–7 breakers/canaries | Loop alerts, resumable freezes, cap/exfil/kill boundaries and scoped canary arms remain in core services; integration clients preserve typed blocked replies and cancelled tickets. `test_app`, `test_canaries`, `test_design_followthrough`. | Actual calibrated thresholds, contemporaneous block profiles and dry-run deployment evidence; fixtures never unlock scientific gates. |
| §6.8 third-party incident page | `IncidentReportService` and optional public listener serve an exact registered identity/form. Bounded, rate-limited unverified reports need authorized human triage; public callers cannot choose platforms/accounts or revoke authority. `test_public_identity`, console CSP regression and actual offline Chromium console smoke. | Operator-owned HTTPS publication and a designated human responder. Interrupted triage is reconciled rather than blindly retried. |
| §6.9 private data/retention | Private child API archives, secret-free selected outputs, service-owned expiration and bounded incident-body cache. `test_provider_boundary`, `test_retention`, `test_public_identity`; [data-protection note](data-protection.md). | Raw immutable inbox/episode provenance may outlive body-cache expiry. An approved collection/redaction/retention policy is required before collecting affected live data; automatic complete erasure is not claimed. |

The optional native smoke scripts are deliberately outside ordinary pytest.
`tests/perception_audio_smoke.py` separately checks actual ffmpeg MP3 encoding,
decoded duration and three unspent quotes inside the selected world image.
Their receipts contain versions, hashes, counts and verification results, not
credentials or raw transcripts. Actual OpenEnv, Inspect, OpenHands and Claude
fixture executions have been exercised; native Harbor additionally requires
the actual Docker environment check against the selected final agent image.
Paid studies, platform permissions, real counterparties, calibrated instruments
and elapsed afterlife windows are external research inputs, not substituted
software results.

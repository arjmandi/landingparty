# Design-to-build audit

This file audits executable software against `00-landing-party.md`. A software
fixture is evidence about implementation, not a completed scientific experiment.
Private reports keep an explicit missing reason wherever actual instruments,
calibration, stakes, counterparties, or elapsed time are unavailable. Section 13's
explicitly deferred topics are not treated as implementation requirements here.

## Final software boundary

The implemented producers and scorers do not fill empirical results. Missing
expert keys/labels, explicit model measurement budgets, provider credentials,
real stake settlement, consenting counterparties/IRB evidence, actual independent
uptake, matched t=0/baseline instruments, sufficient seeds, and elapsed life or
afterlife dates remain explicit research prerequisites. They are not replaced
with synthetic measured values or a passing gate. Historical workspace receipts
are bounded observations: missed pre-restart thresholds and incomplete copies
remain missing, and later source files cannot repair them. Section 13 retains
its explicitly deferred decisions.
